# 浙江创元信息系统服务有限公司官网

这是创元企业官网第一阶段静态网站文件，适用于 GitHub Pages。

## 文件结构
- `index.html`：首页
- `about.html`：关于创元
- `solutions.html`：产品与解决方案
- `service.html`：服务支持
- `news.html`：新闻动态（示例内容，发布前请替换）
- `investor.html`：投资者关系（等待正式资料）
- `contact.html`：联系我们
- `css/style.css`：全站样式
- `js/main.js`：导航与页脚交互
- `assets/logo/`：创元文字标志与网站图标

## GitHub Pages
进入仓库 Settings → Pages，在 Build and deployment 中选择 Deploy from a branch，Branch 选择 `main`，文件夹选择 `/ (root)`，保存。

## 正式上线前检查
1. 确认企业名称、地址、电话、邮箱准确。
2. 替换新闻示例内容。
3. 补充项目案例的真实范围、图片与成果。
4. 根据公司实际情况完善投资者关系栏目。
5. 如有 ICP 备案要求，补充真实备案信息；不要填写虚假备案号。

## 说明
本网站未设置在线表单后端；电话、邮件链接可直接使用。Logo 为可缩放 SVG 矢量图形，可继续调整。
